# EmpathyWorks Leadership

The EmpathyWorks phone app. Leadership coaching and consultation for people who lead in hard places. It runs in Expo Go.

Tagline: Helping people lead well in hard places.

## Run

```bash
npm install
npx expo start --tunnel ngrok --go
```

Open the project in Expo Go for SDK 58. Scan the QR code that command prints. There is no server, no account provider and no card payment. Everything you enter stays on the phone.
